
# Python To-Do List

A command-line task management application built with Python.

## Features

- Add new tasks
- View all tasks
- Mark tasks as completed
- Delete tasks
- Assign Low, Medium, or High priorities
- Filter pending and completed tasks
- Save tasks using JSON file storage
- Validate user input

## Technologies

- Python
- JSON
- Git and GitHub

## Requirements

Python 3.10 or newer.

No external Python packages are required.

## How to Run

1. Download or clone this repository.
2. Open the project folder in your terminal.
3. Run:

   python main.py

4. Select an option from the menu.

## Project Structure

- `main.py` - Application menu and entry point
- `utils/task_manager.py` - Task management functions
- `data/tasks.json` - Task storage

## Storage

Tasks are saved locally in `data/tasks.json`
and remain available when the program is restarted.
